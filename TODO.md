# Gen Lens outcomes

- [x] Local-only setup and launch: the user asked that the program run on localhost and bring localhost up itself; the deliverable must include a one-click launcher and use no Manus-managed services or cloud OCR. Keep records and OCR processing on the user's device. Evidence: Windows/Linux one-click scripts install Python package dependencies, open 127.0.0.1, and the app enforces loopback Host headers; end-to-end response/CSP checks passed.
- [x] PaddleOCR-based extraction: first extract and use the uploaded PaddleOCR project; OCR the image itself (no embedded-text extraction), and process only Patient, ID, Referred by, Gender, Age, Sample type, Source, WES accession, Clinic number, Date collected, and Date reported. The source ZIP must be used as reference; disclose and handle that it does not contain model weights. Evidence: extracted source/docs are included; ZIP had no inference weights, so official PP-OCRv6/orientation weights were added to `data/models/official_models`; actual sample OCR matched all eleven visible values.
- [x] Batch handling and image correction: accept image/PDF files in batches, process through a queue without freezing the interface, and deskew slightly rotated scans before OCR. Evidence: multipart upload API, persistent indexed SQLite queue, paginated 20-item history, separate CPU OCR process, status API remained responsive during OCR, and 2.4° synthetic-tilt sample test recovered all fields.
- [x] Human review and Excel: do not produce nulls or silently infer values; allow corrections and require complete, user-confirmed records before export. Excel contains only the 11 requested fields, one record per row. Evidence: incomplete confirmation was rejected; full API export contained exactly the 11 text columns and one confirmed row; export streams to disk and starts new sheets at Excel's row cap; formula-like values remain literal text.
- [x] User interface and footer: provide a simple modern interface and display “Powered by NEXO”. Evidence: local UI smoke check passed; footer label is present.
- [x] Debug with sample: use the uploaded three-page case image as a local debugging fixture; focus extraction on the top information table and ignore report findings and all non-requested fields. Do not package the case image with the app. Evidence: OCR of uploaded page-one image passed all eleven values; body-text truncation fixed and regression tested; source record removed after E2E test and image excluded from bundle.
